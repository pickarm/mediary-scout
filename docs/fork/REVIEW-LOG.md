## Linux基线回归
- 范围：截至本地f9a3ec2的已提交代码，含F01和F03；未含仍在开发的F02/F04。
- 环境：独立Node22容器、独立PostgreSQL18.6；原有服务未切换。
- 结果：372个测试文件、5289项测试通过，耗时246.07秒。
- 命令：`npm test -- --exclude '**/*.pg.test.ts'`，显式测试admin URL启用仓储PG契约；PG专用文件另行验证。
- 初次环境失败原因：跳过安装脚本导致SQLite原生绑定缺失，以及Windows的core.autocrlf使归档包含CRLF。补齐原生绑定并以`git -c core.autocrlf=false archive`导出后通过，没有删除原测试。
